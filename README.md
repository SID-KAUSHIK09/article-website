# Article Writer Website

A beautiful and modern React website for a Hindi writer and literary author. This platform showcases articles, manages content through an admin dashboard, and provides a seamless reading experience for Hindi literature enthusiasts.

## 🌟 Features

- **Home Page**: Beautiful hero section with writer profile and introduction
- **Articles Section**: Browse and read articles organized by categories
- **Article Detail Pages**: Full article reading experience with rich content
- **Admin Dashboard**: Secure content management system for articles and categories
- **Category Management**: Organize articles into different categories
- **Rich Text Editor**: Create and edit articles with a powerful WYSIWYG editor
- **Responsive Design**: Fully responsive layout that works on all devices
- **Hindi Language Support**: Optimized for Devanagari script with proper font rendering

## 🛠️ Tech Stack

- **Frontend Framework**: React 18.3.1
- **Build Tool**: Vite 7.2.4
- **Routing**: React Router DOM 7.12.0
- **Styling**: Tailwind CSS 4.1.18
- **Backend/Database**: Supabase
- **Rich Text Editor**: React Quill 2.0.0
- **Form Handling**: React Hook Form 7.70.0
- **Language**: JavaScript (ES6+)
